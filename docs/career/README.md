# Career

Professional growth, skill development, and long-term career planning.

Use this folder to track goals, learning direction, and evidence of progress over time.

## What belongs here

- Career goals and planning
- Skill gap assessments
- Learning plans and study tracks
- Portfolio and project impact notes
- Leadership and communication growth plans
- Interview prep and role transition notes

## What does not belong here

- Project architecture documentation
- Technical implementation details
- Team-level engineering standards
- Tooling compatibility references

## Suggested file ideas

- career-roadmap.md
- skill-matrix.md
- quarterly-growth-plan.md
- learning-log.md
- achievements-and-impact.md
- interview-prep.md
