# Decisions

Concise decision records with the outcome and rationale.

Use this folder for smaller or more lightweight decisions that do not need a full ADR, but still should be documented clearly.

## What belongs here

- Short technical decisions
- Why a choice was made
- Outcome summaries
- Notes on rejected alternatives

## What does not belong here

- Full architecture proposals
- Temporary notes
- Task checklists
- Detailed guides
