# Engineering

Engineering practices, standards, and execution principles.

Use this folder to define how work is designed, built, tested, reviewed, and maintained.

## What belongs here

- Coding standards and conventions
- Testing strategy and quality expectations
- Code review guidelines
- Release and deployment practices
- Performance, reliability, and observability practices
- Security and maintainability principles

## What does not belong here

- Personal career goals
- General technology catalogs
- Temporary brainstorming notes
- High-level roadmap planning
