# Checklists

Reusable step-by-step checklists for tasks, reviews, or releases.

Use this folder for repeatable procedures that help ensure consistency and completeness.

## What belongs here

- Release checklists
- Review checklists
- Setup checklists
- QA verification steps
- Operational runbooks in checklist form

## What does not belong here

- Design explanations
- Long-form guides
- Decision records
- Brainstorming notes
