# ADR

Architecture Decision Records describing important technical choices and tradeoffs.

Use this folder for formal records of significant decisions, why they were made, and what alternatives were considered.

## What belongs here

- Decision context
- Options considered
- Chosen approach
- Tradeoff analysis
- Consequences and follow-up actions

## What does not belong here

- Broad design documents
- Implementation checklists
- Casual notes
- Unstructured brainstorming
