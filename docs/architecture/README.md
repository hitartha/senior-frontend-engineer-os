# Architecture

System design, component relationships, and technical structure.

Use this folder for documents that explain how the system is built and how major parts fit together.

## What belongs here

- System overviews
- Component and module relationships
- Data flow and dependency maps
- Technical architecture diagrams
- Platform and infrastructure notes
- Performance, scalability, and reliability design

## What does not belong here

- Task notes
- Temporary brainstorming
- Process checklists
- Final decisions without architectural context
