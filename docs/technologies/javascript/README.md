# Roadmap

Long-term direction, milestones, and planned work.

Use this folder for planning future initiatives, sequencing major efforts, and tracking where the work is headed over time.

## What belongs here

- Quarterly or release roadmaps
- Milestone plans
- Planned features and initiatives
- Timeline summaries
- Priority and sequencing notes

## What does not belong here

- Detailed technical designs
- Temporary brainstorming
- Final architecture decisions
- Step-by-step how-to instructions
