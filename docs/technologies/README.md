# Technologies

Tools, platforms, frameworks, and technical choices used across projects.

Use this folder to document what technologies are used, why they are chosen, and how they fit into your engineering workflows.

## What belongs here

- Tech stack overviews
- Frontend, backend, and infrastructure tooling lists
- Version and compatibility notes
- Technology evaluation summaries
- Migration plans between tools or frameworks
- Preferred libraries and alternatives

## What does not belong here

- Career reflections
- Team process checklists
- Personal growth plans
- Broad project roadmaps

- stack-overview.md
- frontend-technologies.md
- backend-technologies.md
- infra-and-devops.md
- tooling-standards.md
- migration-notes.md
